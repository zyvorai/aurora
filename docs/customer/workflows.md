# Common workflows

## First product (admin)

1. Sign in → [GTM workspace](pages/workspace/dashboard.md)
2. Create product with website/docs URL
3. [Full Forge](pages/product/products-id.md) → Add source → Ingest → wait **completed**
4. Open Brief; run one agent tab; Approve → Publish

## Sales day

1. [Sales Action](pages/product/products-id-sales.md) — Discover / Qualify / Outreach
2. [Pipeline](pages/product/products-id-pipeline.md) — create opportunity, move stages

## Approve without Forge chrome

1. [Executive Brief](pages/product/products-id-brief.md)
2. Jump to Forge only when ingest or publish is required

## Admin portals

1. [Portal Accounts](pages/admin/dashboard-admin-portal-accounts.md) — approve signups
2. [Support Tickets](pages/admin/dashboard-admin-tickets.md)
