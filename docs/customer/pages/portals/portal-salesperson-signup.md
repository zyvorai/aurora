# Salesperson portal signup

## Purpose

Salesperson portal signup — Aurora surface at `/portal/salesperson/signup`.

## When to use it

- Operate **Salesperson portal signup** when your job matches this page
- Admin lands on Full Forge by default; editors on Sales; approvers/viewers on Brief
- Confirm auth and that workers are up if ingest never completes

## How to get there

- Route: `/portal/salesperson/signup`
- Nav: **Portals → Salesperson portal signup**

## Operate from the console (UX)

1. `/portal/salesperson/signup`.
2. Submit signup request.
3. **Empty / fail:** —.
4. **Success:** Request pending.

Use `http://<host>:3000` for the web UI and `http://<host>:8000/health` for the API. Never publish lab IPs in customer docs.
