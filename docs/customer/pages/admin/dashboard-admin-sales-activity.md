# Sales Activity

## Purpose

Sales Activity — Aurora surface at `/dashboard/admin/sales-activity`.

## When to use it

- Operate **Sales Activity** when your job matches this page
- Admin lands on Full Forge by default; editors on Sales; approvers/viewers on Brief
- Confirm auth and that workers are up if ingest never completes

## How to get there

- Route: `/dashboard/admin/sales-activity`
- Nav: **Admin → Sales Activity**

## Operate from the console (UX)

1. Admin → Sales Activity.
2. Review rep↔client activity.
3. **Empty / fail:** No activity.
4. **Success:** Activity rows.

Use `http://<host>:3000` for the web UI and `http://<host>:8000/health` for the API. Never publish lab IPs in customer docs.
