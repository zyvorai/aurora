# Workflow Stages

## Purpose

Workflow Stages — Aurora surface at `/dashboard/admin/workflow-stages`.

## When to use it

- Operate **Workflow Stages** when your job matches this page
- Admin lands on Full Forge by default; editors on Sales; approvers/viewers on Brief
- Confirm auth and that workers are up if ingest never completes

## How to get there

- Route: `/dashboard/admin/workflow-stages`
- Nav: **Admin → Workflow Stages**

## Operate from the console (UX)

1. Admin → Workflow Stages.
2. Add/edit custom Full Forge stages (Enterprise).
3. **Empty / fail:** —.
4. **Success:** Stage saved.

Use `http://<host>:3000` for the web UI and `http://<host>:8000/health` for the API. Never publish lab IPs in customer docs.
