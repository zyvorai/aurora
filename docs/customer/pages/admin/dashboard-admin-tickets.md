# Support Tickets

## Purpose

Support Tickets — Aurora surface at `/dashboard/admin/tickets`.

## When to use it

- Operate **Support Tickets** when your job matches this page
- Admin lands on Full Forge by default; editors on Sales; approvers/viewers on Brief
- Confirm auth and that workers are up if ingest never completes

## How to get there

- Route: `/dashboard/admin/tickets`
- Nav: **Admin → Support Tickets**

## Operate from the console (UX)

1. Admin → Tickets.
2. Triage customer tickets.
3. **Empty / fail:** No tickets.
4. **Success:** Ticket updated.

Use `http://<host>:3000` for the web UI and `http://<host>:8000/health` for the API. Never publish lab IPs in customer docs.
