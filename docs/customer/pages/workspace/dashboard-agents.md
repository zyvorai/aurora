# Agent Registry

## Purpose

Agent Registry — Aurora surface at `/dashboard/agents`.

## When to use it

- Operate **Agent Registry** when your job matches this page
- Admin lands on Full Forge by default; editors on Sales; approvers/viewers on Brief
- Confirm auth and that workers are up if ingest never completes

## How to get there

- Route: `/dashboard/agents`
- Nav: **Workspace → Agent Registry**

## Operate from the console (UX)

1. Nav Agents.
2. Browse agent catalog / tiers.
3. **Empty / fail:** Empty catalog → check plan.
4. **Success:** Agents listed.

Use `http://<host>:3000` for the web UI and `http://<host>:8000/health` for the API. Never publish lab IPs in customer docs.
