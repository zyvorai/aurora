# Settings

## Purpose

Settings — Aurora surface at `/dashboard/settings`.

## When to use it

- Operate **Settings** when your job matches this page
- Admin lands on Full Forge by default; editors on Sales; approvers/viewers on Brief
- Confirm auth and that workers are up if ingest never completes

## How to get there

- Route: `/dashboard/settings`
- Nav: **Workspace → Settings**

## Operate from the console (UX)

1. Nav Settings.
2. Profile.
3. Appearance.
4. Plan usage.
5. Suppression list.
6. Sign out.
7. deep-links to admin.
8. **Empty / fail:** —.
9. **Success:** Settings persist.

Use `http://<host>:3000` for the web UI and `http://<host>:8000/health` for the API. Never publish lab IPs in customer docs.
