Try Aurora

Pick your platform. Each option runs the same four containers: Postgres, Qdrant, the API and the web app.

Needs Docker Desktop running and about 4 GB free RAM. Works on Apple Silicon and Intel.

# install and start (opens http://localhost:3000) curl -fsSL {{BASE_ABS}}/install.sh | bash

Sign in with marketing@zyvor.dev / Admin@321. For fast local AI on Apple Silicon, choose "Ollama already running on this computer" when asked.

Needs Docker Engine with Compose v2 (install guide). amd64 and arm64.

# install and start curl -fsSL {{BASE_ABS}}/install.sh | bash

Then open http://localhost:3000. Prefer not to pipe to a shell? Download install.sh, read it, and run it.

Needs Docker Desktop with the WSL2 backend, running.

# PowerShell irm {{BASE_ABS}}/install.ps1 | iex
Heads-up: the Windows installer is written and linted but has not yet been run on a real Windows machine. If anything looks off, tell us - it helps a lot.

Any cluster, or a throwaway local one with kind or k3d.

# coming with the Helm PoC chart ./scripts/poc/install-k8s.sh
The Kubernetes PoC chart is in progress. Until then use the Docker options above, or see k8s/README.md for the lab manifests.

No script, just Docker Compose:

curl -fsSLO {{BASE_ABS}}/docker-compose.poc.yml docker compose -f docker-compose.poc.yml up -d --wait

Settings (LLM key, secrets) go in a .env next to the file. See the PoC guide.

A native SwiftUI client for macOS 14+ (Apple Silicon and Intel) that connects to any Aurora server: the PoC at http://localhost:3000 or your own. Sandboxed; the sign-in token is kept in the Keychain.

Download the latest DMG

The DMG is Developer ID signed and notarized by Apple, so it opens without a Gatekeeper warning. If the releases page has no DMG yet, the first release has not been cut: use the Docker option for now.

After it starts

  • Create a product from your website URL, then ingest it.
  • SEO tab: audit a public page and score a draft.
  • Run ~/.aurora-poc/aurora-poc status any time; reset wipes the data; feedback opens the feedback form.
